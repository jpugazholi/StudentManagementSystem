📌 Overview

Student Management System is a Java-based desktop application developed using Java Swing in Apache NetBeans IDE.

The application provides a graphical interface to perform basic student record management operations. It is designed as a beginner-friendly project to demonstrate Java programming, object-oriented design, GUI development, and CRUD operations.

💡 Project goal: Make student record management simple, organized, and easy to use.
✨ Features

<table> <tr> <td width="50%"> <h3>➕ Add Students</h3> Add student records with ID, name, department, and year. </td> <td width="50%"> <h3>📋 View Records</h3> Display student details in a structured table. </td> </tr> <tr> <td width="50%"> <h3>✏️ Update Details</h3> Modify existing student information. </td> <td width="50%"> <h3>🗑️ Delete Records</h3> Remove student records with confirmation. </td> </tr> <tr> <td width="50%"> <h3>🔍 Search Students</h3> Find records using the Student ID. </td> <td width="50%"> <h3>🛡️ Input Validation</h3> Check required fields and prevent duplicate IDs. </td> </tr> </table>

⚙️ Installation & Setup
Prerequisites

Make sure you have installed:

Java Development Kit (JDK)
Apache NetBeans IDE
Git (optional, for cloning the repository)
1️⃣ Clone the Repository

Open Command Prompt or Terminal and run:

git clone https://github.com/jpugazholi/StudentManagementSystem.git

2️⃣ Open in NetBeans
Launch Apache NetBeans IDE.
Select File → Open Project.
Choose the cloned StudentManagementSystem folder.
Wait for NetBeans to load the project.
3️⃣ Run the Application
Expand Source Packages.
Open studentmanagementsystem.
Open StudentManagement.java.
Right-click the file and select Run File.
🧭 How to Use
Enter the Student ID.
Enter the student's name.
Enter the department.
Enter the academic year.
Click Add Student to add the record.
Select a table row to edit or delete a student.
Use Search ID to find a particular student.
Click Show All to display all current records.
⚠️ Data Storage

The current version uses Java ArrayList for temporary data storage.

Important: Student records are held in memory and will be lost when the application closes. A database is not yet integrated.
